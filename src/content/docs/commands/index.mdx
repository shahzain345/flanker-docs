Use your server’s prefix, usually `,`, before a command. Examples use `,`; replace it if your server uses another prefix. Required arguments use `(round brackets)` and optional arguments use `[square brackets]`.

See the [typed slash reference](/guides/slash-commands/) for every slash path and its fields. Slash commands use Discord’s typed fields. Some commands are server-only; installing Flanker on your profile does not grant moderation or security access. See [profile installation](/guides/user-install/).
