title: Invite tracking
description: See who invited whom, with join and leave counts.
---

flanker tracks which invite each member joined from, so you can credit inviters
and run invite-based rewards.

## What it tracks

- The invite and inviter for each new member.
- Per-member invite counts (joins, leaves, and net invites).
- A server invite leaderboard.

Use the invite commands (`,invites`) to view counts and the leaderboard. See the
[Logging, invites, levels reference](/commands/logging-invites-levels/).

## On the dashboard

Open the [dashboard](https://flanker.wtf/dashboard), pick your server, and go to
**Invites** to see tracked invites and configure invite settings.

:::tip
Pair this with [Logging](/guides/logging/): the **invites** log group records
invite creation and which invite each join used.
:::
