These paths come from Flanker’s registered slash-command catalog. Required fields must be supplied in Discord; do not paste an entire prefix command into one field. Some roots split into numbered groups to fit Discord’s limits.

**Profile installation only** filters to personal commands. Available contexts still depend on Discord and the channel’s external-app settings. Commands keep their normal permission, account-linking and participant checks.

For examples and full feature behavior, use the [prefix command reference](/commands/). The `/confess` entry is the additional server-only form command registered outside the generated catalog.
