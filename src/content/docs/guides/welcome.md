flanker can greet new members, say goodbye to leavers, and assign roles on join,
all with fully customisable messages.

## Welcome and leave

- Set a welcome message that fires when a member joins.
- Set a leave message for when they go.
- Messages can be plain text, embeds, or rich Components V2 "cards" with
  buttons, built visually on the [dashboard](https://flanker.wtf/dashboard).

See `,help welcome` and the [Welcome commands](/commands/welcome-and-messages/).

## Autoroles and sticky roles

- **Autoroles** assign one or more roles automatically on join.
- **Sticky roles** restore a member's roles when they rejoin.

## The message builder

Welcome messages, embeds, tickets, autoresponders and more share the same
message builder. In it you can:

- Write text, add an embed, or build a card.
- Add buttons and menus, and place them **inside** the card or **outside** it,
  per block.
- Preview the result live before saving.

## Autoresponders

Set triggers that make flanker reply to a keyword or phrase. See
`,help autoresponder` (or the relevant entry in the
[command reference](/commands/welcome-and-messages/)).
